Rethinking Uncertainty: A Bayesian Perspective on Machine Learning

While modern deep learning and large-scale AI models deliver unprecedented predictive power, they frequently struggle with uncalibrated confidence, opaque black-box dynamics, and a lack of reliable uncertainty estimation. This workshop examines how a Bayesian perspective offers a principled framework to quantify model uncertainty, incorporate domain priors, and build safer, more trustworthy systems.

⚡ Workshop Artifacts: Work through the instructional demonstration on Bayesian linear regression with Zellner's g-prior, then complete the guided tasks in Bayesian logistic regression with Metropolis-Hastings MCMC!

Step-by-Step Project Guide

Workshop Tasks & Milestone Instructions

Follow these instructions step-by-step to complete the 7 # TODO: milestone blocks in your Bayesian logistic regression notebook.

TASK 1

Binary Target Encoding (TODO 1)

Convert the text diagnosis column in the Wisconsin Breast Cancer dataset to a numerical binary vector where 'M' (Malignant) is encoded as 1 and 'B' (Benign) is encoded as 0.

  • Extract the diagnosis column from the loaded DataFrame and evaluate the boolean condition for malignancy.
  • Cast the resulting booleans to integer values (0 or 1) as a NumPy array to form your training target vector y.
  • Inspect the resulting class balance across the 569 biopsy samples (357 benign vs. 212 malignant).
TASK 2

Numerically Stable Sigmoid Function (TODO 2)

Implement the standard logistic sigmoid activation function with input bounding to prevent floating-point exponential overflow warnings.

  • During MCMC exploration, candidate coefficient vectors may produce extreme values of the linear predictor z.
  • Clip input values of z to a stable numerical range (such as [-500.0, 500.0]) using np.clip before computing the exponential.
  • Return 1.0 / (1.0 + np.exp(-z_clipped)) to guarantee probabilities strictly bounded in (0, 1).
TASK 3

Bernoulli Log-Likelihood & Log-Posterior (TODO 3)

Formulate the sum of individual log-likelihoods for independent Bernoulli observations and combine it with the Gaussian prior to evaluate the unnormalized log-posterior.

  • Compute the linear predictor vector xb = X @ beta across all patient observations.
  • Use the numerically robust log-sum-exp trick via np.logaddexp(0.0, xb) to avoid overflow when calculating log(1 + exp(x_i^T β)).
  • Combine the log-likelihood with the independent zero-mean Gaussian prior log-density to return the total log-posterior value.
TASK 4

Metropolis-Hastings Proposal Acceptance Rule (TODO 4)

Implement the Metropolis-Hastings acceptance ratio and decision rule for proposed candidate states in the Random Walk sampler.

  • Compute the log acceptance ratio: log_r = log_post_prop - log_post_curr.
  • Sample a uniform random draw u ~ Uniform(0, 1) and test whether log(u) ≤ log_r.
  • If accepted, transition to the proposed state; otherwise, retain the current state and record the rejection.
TASK 5

Pilot Chain Proposal Tuning (TODO 5)

Inspect acceptance rates across candidate proposal variances (from 0.5 to 100) and identify the proposal scale that maximizes MCMC mixing efficiency.

  • Examine the pilot grid search output table displaying acceptance rates for each tested variance scale.
  • Identify the variance producing an acceptance rate closest to the optimal 30%–35% theoretical Goldilocks window for multivariate random walks.
  • Set optimal_sigma2_prop to your selected variance scale to calibrate the full production MCMC sampler.
TASK 6

Posterior Inclusion Probabilities via SSVS (TODO 6)

Calculate empirical Posterior Inclusion Probabilities (PIPs) from the post-burnin indicator chain and filter features exceeding the Median Probability Model threshold.

  • Compute PIP for each predictor as the sample mean of the binary indicator draws along the iteration axis after discarding burn-in iterations.
  • Assemble a sorted ranking of all 30 cytology features by their posterior inclusion probabilities.
  • Filter for biomarkers that satisfy the Barbieri & Berger Median Probability Model criterion (PIP ≥ 0.50).
TASK 7

Clinical Odds Ratios & Decision Reflection (TODO 7)

Transform effective logit coefficients to multiplicative Odds Ratios (OR = exp(β)) with 95% Credible Intervals, and complete the three clinical reflection prompts.

  • Exponentiate posterior coefficient draws to calculate posterior means and 2.5% / 97.5% percentiles for clinical Odds Ratios.
  • Reflect on how unit standard-deviation increases in selected biomarkers multiply the relative odds of tumor malignancy.
  • Answer the guided analytical prompts regarding parameter shrinkage, model parsimony, and how posterior credible intervals safeguard patient care.
