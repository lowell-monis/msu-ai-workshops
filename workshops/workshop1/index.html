Execution & Workflow Guide

Quickstart: Clone & Run the Project

Use the Jupyter Notebook for visual demonstration, then work through the modular scripts to modify and enhance the project.

1. Clone Template Repository & Install Dependencies

# Clone the standalone template repository
git clone https://github.com/lowell-monis/palmer-penguins-ml-template.git
cd palmer-penguins-ml-template

# Install required Python packages
pip install pandas numpy scikit-learn plotly jupyter

2. Workflow Step A: Visual Demo via Notebook

Run penguin_classifier.ipynb for live exploratory data analysis, Plotly scatter charts, and step-by-step pipeline execution: 

jupyter notebook penguin_classifier.ipynb

3. Workflow Step B: Modular Code Execution & Modification

Inspect and modify train.py and predict.py to add new features or tune hyperparameters: 

# Train the Random Forest model (downloads data dynamically from Data URL)
python train.py

# Run CLI inference for custom penguin bill/flipper measurements
python predict.py --bill_length 48.5 --bill_depth 15.0 --flipper_length 217 --body_mass 5000

Repository Architecture

How to Organize Files Inside an ML Repository

Best practices for structuring scripts, datasets, notebooks, and git ignore rules inside a clean machine learning codebase.

1. Clean Repository Directory Layout

palmer-penguins-ml-template/
├── README.md                   # Project Overview, Setup Commands & Model Card
├── .gitignore                  # Ignore rules for bytecode, caches, & model binaries
├── train.py                    # 5-stage Data Lifecycle training pipeline script
├── predict.py                  # Real-time CLI inference script
└── penguin_classifier.ipynb    # Notebook alternative (EDA & Plotly visual charts)

2. File Organization Rules & Data Governance

  • Never Commit Raw Data CSVs: Raw datasets should never be committed directly to git history. Load data dynamically via public URLs (DATA_URL = "https://raw.githubusercontent.com/mwaskom/seaborn-data/master/penguins.csv") or download helper scripts.
  • Organize Flat Starter Code: The template repository provides a flat starter layout. Attendees will structure the files into clean project directories (e.g. src/, notebooks/, models/) following this guide.
  • Provide a Notebook Alternative: Include penguin_classifier.ipynb for live demos, while maintaining clean Python scripts (train.py, predict.py) for reproducible execution.
  • Ignore Generated Binary Artifacts: Always list serialized model binaries (penguin_model.pkl) and bytecode (__pycache__) in .gitignore.

3. Recommended Project Enhancement Challenges

  • Challenge 1: Feature Engineering: Add a new feature bill_ratio = bill_length_mm / bill_depth_mm in train.py and test if classifier accuracy improves.
  • Challenge 2: Classifier Comparison: Train and compare a Logistic Regression model vs Decision Tree vs Random Forest in penguin_classifier.ipynb.
  • Challenge 3: Custom Data Download Script: Write a download_data.py script using urllib or requests to fetch and save data locally outside git tracking.
