Execution & Reproduction Guide

Quickstart: Run the ML Pipeline Locally

Follow these step-by-step terminal commands to execute the pipeline, train the classifier, and run CLI predictions.

Option 1: Run Locally via Python Terminal

# 1. Navigate to Workshop 1 directory
cd msu-ai-workshops/workshops/workshop1

# 2. Install required Python packages
pip install pandas numpy scikit-learn plotly jupyter

# 3. Execute the Model Training Pipeline (creates penguin_model.pkl)
python train.py

# 4. Run CLI Predictions on custom penguin measurements
python predict.py --bill_length 48.5 --bill_depth 15.0 --flipper_length 217 --body_mass 5000

# 5. Run Automated Pipeline Verification Tests
python verify_pipeline.py

Option 2: Interactive Jupyter Notebook

# Launch Jupyter Notebook interface
jupyter notebook penguin_classifier.ipynb

*Expected Outcome*: Running verify_pipeline.py passes all 4 automated unit test stages, achieving >95% accuracy on species classification.

Core Engineering Pipeline

The 5 Stages of the Data Lifecycle Pipeline

How raw environmental data moves from initial collection to an evaluated, production-ready machine learning artifact.

1. Generation & Ingestion

Raw physical measurement collection from Palmer Station Antarctica LTER (`penguins.csv`). Captures bill length, bill depth, flipper length, body mass, and sex across 344 penguin observations.

2. Processing & Cleaning

Handling missing values resulting from field collection challenges. Applies **Median Imputation** to numeric measurements and **Mode Imputation** to categorical attributes (`sex`), preserving 100% of observation records.

3. Preprocessing & Feature Matrix

Structuring continuous feature matrix $X$ and target vector $y$. Stratified train/test splitting (80/20) to ensure balanced representation across species cohorts.

4. Model Training & Evaluation

Training a `RandomForestClassifier` (100 estimators, max depth 5). Evaluated using Precision, Recall, F1-Scores, Feature Importances, and Confusion Matrix metrics (>95% accuracy score).

5. Export & Inference CLI

Serializing model binary artifact to `penguin_model.pkl` and deploying a standalone CLI prediction script (`predict.py`) for real-time inference on new penguin measurements.

GitHub Portfolio Integration

Organizing Your Repository on GitHub

How to structure, format, and present this project on your personal GitHub profile to showcase for portfolio websites.

1. Create & Push Your Project Repository

# Create a new local directory
mkdir palmer-penguins-ml-classifier
cd palmer-penguins-ml-classifier

# Copy project files into directory (penguins.csv, train.py, predict.py, penguin_classifier.ipynb, verify_pipeline.py, README.md)
git init
git add .
git commit -m "Initial commit: Palmer Penguins ML Classifier & Data Lifecycle Pipeline"

# Push to your personal GitHub profile
git remote add origin https://github.com/YOUR_USERNAME/palmer-penguins-ml-classifier.git
git branch -M main
git push -u origin main

2. Recommended Repository Structure
